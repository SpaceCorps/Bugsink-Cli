## Bugsink Error Tracker
Bugsink is an open-source, self-hosted error tracker compatible with Sentry SDKs:
- **Self-Hosted Community Edition**: 100% free and open source. Host on your own virtual machines, Docker containers, or Kubernetes clusters.
- **Data Sovereignty**: Complete ownership over error payloads, user privacy, and retention periods without third-party SaaS cloud fees.

For official Bugsink project documentation and details, visit [https://www.bugsink.com](https://www.bugsink.com).
