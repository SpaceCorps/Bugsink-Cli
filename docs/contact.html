Contact & Technical Support

We welcome questions, issue reports, integration feedback, and feature proposals for Bugsink CLI. Below are the official contact and support channels available to users, developers, and autonomous agent integrators.

Primary Support Channels

  • GitHub Issues: For reporting bugs, unexpected behavior, and enhancement proposals, visit the official issue tracker at github.com/SpaceCorps/Bugsink-Cli/issues.
  • GitHub Discussions: For architectural questions, agent workflows, and community integration patterns, join our GitHub discussions board at github.com/SpaceCorps/Bugsink-Cli/discussions.
  • Organization Profile: To learn more about our open-source software tools and ongoing engineering initiatives, visit SpaceCorps on GitHub at github.com/SpaceCorps.

Security Inquiries

If you have discovered a potential security vulnerability within the CLI binary, credential handling routines, or secret store integration, please file a confidential report via GitHub Private Vulnerability Reporting on the repository page or reach out directly to the maintainers.

Platform Inquiries

For questions related to the underlying Bugsink server software, visit the official Bugsink repository at github.com/bugsink/bugsink or consult the official documentation at bugsink.com.
